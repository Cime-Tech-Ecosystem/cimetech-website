# Cime Tech Ecosystem Website

A static multi-page marketing website for Cime Tech Ecosystem Ltd., showcasing the company’s technology solutions, community hub, and business offerings.

## About the website

This project promotes Cime Tech as a technology and community platform that helps individuals and businesses build, secure, and scale with confidence. The site highlights:

- The Cime Hub co-working and community space
- Software development and digital transformation services
- Network, cloud, cybersecurity, and business intelligence solutions
- Booking tours and starting projects
- Contact, partner, and privacy information

## Website sections

The site includes dedicated pages for:

- Home
- About
- The Cime Hub
- Solutions
- Partners
- Insights
- Contact
- Book a Hub Tour
- Start a Project
- Privacy Policy
- 404 page
